2. Какие данные мы собираем

2.1 Данные зарегистрированного пользователя

Email, ФИО или название компании, образец подписи (изображение), содержимое загружаемых документов.

2.2 Данные контрагента по сделке (Deal Cycle)

Контрагент — сторона, которая подписывает документ по временной ссылке без регистрации. Мы собираем: содержимое документа, который он подписывает; IP-адрес и user-agent браузера в момент подписания (фиксируются в юридическом блоке итогового PDF как часть доказательства факта подписания); изображение или скан подписи, которую он ставит. Открывая ссылку на подписание и отмечая чекбокс согласия на ПЭП, контрагент соглашается на обработку этих данных в целях, описанных в этом документе.

2.3 Технические и аналитические данные

IP-адрес, тип устройства и браузера, действия на сайте — собираются через PostHog на всех страницах сервиса, включая страницу подписания для контрагента (не только в личном кабинете).

3. Цели обработки

Предоставление функциональности сервиса; обеспечение юридической значимости факта подписания документа; техническая поддержка; улучшение сервиса на основе аналитики использования.

4. Кому передаются данные

  • LLM-провайдеры (Anthropic, OpenAI, DeepSeek, Google Gemini) — текст загружаемого документа передаётся для автоматического поиска мест подписи. Какой провайдер активен в моменте — настраивается Оператором.
  • Google Cloud / Firebase — хранение данных и файлов, регион europe-west1 (Евросоюз).
  • PostHog (аналитика) — обработка в ЕС (eu.i.posthog.com).

Данные не продаются третьим лицам и не используются в рекламных целях.

5. Международная передача данных

Часть LLM-провайдеров обрабатывает данные за пределами ЕС (США — Anthropic, OpenAI, Google; Китай — DeepSeek). Загружая документ в сервис, пользователь соглашается с такой передачей в объёме, необходимом для работы функции автоматического поиска мест подписи.

6. Сроки хранения

Подписанные документы (Deal Cycle) хранятся 7 дней с момента истечения срока действия ссылки, затем удаляются автоматически. Данные профиля пользователя (email, ФИО, образец подписи) хранятся до удаления аккаунта.

7. Права пользователя

Запросить копию своих данных, исправить неточности или потребовать удаления — обращение на alebedzeu@gmail.com. Контрагент, чьи IP/UA зафиксированы в подписанном документе, может обратиться с тем же запросом, но зафиксированные в уже переданном контрагентам PDF данные технически не могут быть отозваны из уже скачанных копий документа.

8. Безопасность

Данные передаются по HTTPS, хранятся в защищённой инфраструктуре Google Cloud. Доступ к продовой инфраструктуре ограничен Оператором лично.
